추천 시간은 이렇게 정해요

· 본편: 화 오전 7시 · 일 오전 8시 — 180만 개 영상 분석에서 롱폼은 아침(8~11시)과 일요일 오전이 가장 강했고, 한국 유튜브 사용시간도 일요일이 가장 길어요. 피크 1~2시간 전에 올려 유튜브가 먼저 시험 노출할 시간을 줘요.

· 본편 쇼츠: 월~토 저녁 6시 (금은 5시) — 쇼츠는 저녁 6~11시, 특히 금요일 오후·저녁이 가장 강했어요. 본편이 나간 뒤에만 공개해요.

· 데일리 시장 쇼츠: 화~토 낮 12시 — 미국장 다음 날 점심시간에 올려요. 본편 쇼츠와 6시간 떨어져 있어서 서로 노출을 나눠 먹지 않아요.

· 이미 잡힌 예약과 겹치지 않게 비어 있는 다음 칸에 넣어요. 채널마다 시청자 시간이 달라서, 유튜브 스튜디오 '시청자' 탭 자료가 쌓이면 시간을 다시 맞춰요.

올리는 동안 이 화면을 켜 두세요. 영상 하나에 30초쯤 걸려요. 하루 최대 100개까지 올릴 수 있어요.

인스타 게시물

카드뉴스와 릴스(유튜브 쇼츠 영상)를 체크하고 버튼 하나로 차례대로 올려요. 누르면 바로 공개돼요.

유튜브 연결 방법 (처음 한 번만)

10분 정도 걸려요. 키는 노아 님만 볼 수 있는 Vercel 환경변수에만 넣어요.

  1. Google Cloud에서 새 프로젝트를 만들고, 'API 및 서비스 → 라이브러리'에서 YouTube Data API v3를 사용 설정해요.
  2. 'OAuth 동의 화면'에서 외부 앱을 만들고, 게시 상태를 '프로덕션'으로 바꿔요. 테스트 상태면 7일마다 연결이 끊겨요.
  3. '사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션'을 만들고, 승인된 리디렉션 URI에 아래 주소를 그대로 넣어요.
  4. Vercel → 판독기 프로젝트 → Settings → Environment Variables에 YT_CLIENT_ID, YT_CLIENT_SECRET을 넣고 Redeploy해요.
  5. 다시 이 화면으로 와서 '유튜브 연결'을 눌러요.

Vercel에 ACCESS_CODE도 꼭 넣어 주세요. 접근 코드가 없으면 업로드 버튼이 잠겨 있어요.
