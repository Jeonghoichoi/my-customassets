# 저점 판독기

미국 주식을 검색하면 일곱 투자자(래리 윌리엄스, 워렌 버핏, 찰리 멍거, 피터 린치, 스탠리 드러켄밀러,
빌 애크먼, 마이클 버리)의 공개된 원칙을 수치 규칙으로 옮겨 "지금 가격이 저점인가"를 판독합니다.
외부 패키지 없이 Node.js 18 이상만 있으면 됩니다.

## 로컬 실행

데모 데이터로 바로 보기:

    npm run demo

실제 데이터: .env.example 을 .env 로 복사하고 키를 넣은 뒤

    npm start

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 올립니다 (.env 는 올리지 않습니다)
2. vercel.com 에서 New Project 로 저장소를 가져옵니다. Framework Preset 은 Other, 빌드 설정은 비워 둡니다
3. Settings > Environment Variables 에 FRED_API_KEY, FMP_API_KEY 를 넣습니다
   (선택: ANTHROPIC_API_KEY, ACCESS_CODE)
4. Deploy 를 누르면 https://프로젝트명.vercel.app 주소가 생깁니다

키를 넣지 않고 배포하면 데모 모드로 뜹니다. 키를 넣은 뒤에는 Redeploy 해야 반영됩니다.
마진 부채를 갱신할 때는 data/margin-debt.json 을 고쳐 커밋하면 자동으로 다시 배포됩니다.

## 앱처럼 설치

배포 주소를 휴대폰에서 연 뒤

- 아이폰 Safari: 공유 버튼 > 홈 화면에 추가
- 안드로이드 Chrome: 메뉴 > 앱 설치 (또는 홈 화면에 추가)

앱스토어·플레이스토어 등록이 필요하면 pwabuilder.com 에 배포 주소를 넣어 안드로이드·iOS 패키지를 만들 수 있습니다.

## 판독 규칙

- src/engine/macro.js: 시장 판독 11개 신호(구리, 구리/금 비율 포함), 원자재 요약, 최상단 해석 문구
- src/engine/judges.js: 일곱 투자자 판독, 투자자별 성향(PROFILES), 월가 의견 비교, 기술적 신호(RSI, 스토캐스틱, 윌리엄스 %R)
- src/router.js: 대형 증권사 시각 요약과 판독기 신호 비교
- 기준값은 모두 이 두 파일 안의 숫자이니 본인 원칙에 맞게 고쳐 쓰세요

## 연동 점검

배포 후 https://주소/api/check/VZ 를 열면 FRED·FMP 각 데이터가 들어오는지와 필드명이 보입니다.
접근 코드를 설정했다면 화면에서 코드를 한 번 입력한 뒤, 같은 브라우저 개발자 도구에서 확인하거나 잠시 ACCESS_CODE를 비우고 확인하세요.

국내 종목 데이터 점검: https://주소/api/check/KR

## 알아둘 점

- FMP 응답 필드명은 API 버전에 따라 다를 수 있습니다. 값이 "자료 없음"으로 나오면 src/sources/fmp.js 의 pick(...) 후보에 실제 필드명을 추가하세요
- 국내 종목은 네이버 증권의 공개 데이터를 씁니다. 공식 API가 아니어서 구조가 바뀌면 src/sources/naver.js 를 고쳐야 합니다
- 검색창 자동완성은 public/stocks.json 의 주요 종목 목록을 먼저 쓰고, 목록에 적을 때만 서버 검색을 합니다
- 접근 코드는 무료 API 한도를 지키기 위한 장치입니다. 시세 응답은 Vercel CDN에 몇 분간 캐시됩니다
- 판독 결과는 원칙을 기계적으로 적용한 것이며, 실제 인물의 의견이나 투자 권유가 아닙니다
